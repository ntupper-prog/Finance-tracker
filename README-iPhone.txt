POCKET LEDGER — iPHONE HOME SCREEN VERSION

This is a Progressive Web App (PWA) bundle, not a signed native iOS app.
Because iOS requires a secure origin to install a web app reliably, publish these static files to an HTTPS host once, then open the site in Safari and choose Share > Add to Home Screen.

Privacy:
- Transaction data is stored in the browser's local storage on the device.
- The app does not send your transactions to a server.
- The static hosting provider serves the app files only; it does not receive transaction records through this app.
- Do not clear Safari website data unless you have exported a backup.
- The Excel reader currently loads from a CDN, so Excel import may require internet. CSV import is the most dependable offline option.

This PWA is not encrypted at app level and does not use Face ID. Use sample data until security is improved.
